# Hrid Digital Group website

Source for https://hriddigitalgroup.com. Hosted on Netlify, which serves the `site/` folder.

- Edit pages in `src/pages/`, shared header/footer and contact details in `build.py`, colours in `site/assets/style.css`.
- Run `python3 build.py` to regenerate `site/`, then commit both.
- Launch and domain setup: see [LAUNCH-STEPS.md](LAUNCH-STEPS.md).
